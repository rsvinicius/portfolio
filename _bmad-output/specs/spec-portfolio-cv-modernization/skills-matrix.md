# Skills Matrix & Open Source Catalog

## 1. 4-Layer Architectural Skills Taxonomy

### Layer 1: Backend Core & JVM Ecosystem
- **Languages & Runtimes:** Java, Kotlin.
- **Frameworks & Dependency Injection:** Spring Boot, Spring Webflux, Spring Batch, Javalite, Google Guice.
- **Execution Engineering:** Concurrency, Multithreading, Thread Pools, Non-blocking I/O, Reactive Streams.

### Layer 2: Distributed Systems, Data & Scale
- **Architecture & Patterns:** Microservices, Distributed Systems.
- **Databases & Storage:** PostgreSQL, MongoDB, Redis.
- **Messaging & Processing:** RabbitMQ, ActiveMQ, Spring Batch, Quartz Scheduler, File Streaming.

### Layer 3: Cloud, DevOps & Infrastructure Architecture
- **Cloud Infrastructure (AWS):** AWS S3, AWS Lambda.
- **Protocols & Pipelines:** SFTP pipelines, RESTful APIs.
- **Containers & CI/CD:** Docker, GitHub Actions CI/CD.

### Layer 4: AI-Augmented Engineering & Modern SDLC
- **AI Systems & Context:** Retrieval-Augmented Generation (RAG), Model Context Protocol (MCP).
- **Agentic Orchestration:** Multi-agent architectures, BMAD framework.
- **Modern Development Tooling:** Claude Code, Gemini CLI, Opencode, AI-assisted regression testing.
